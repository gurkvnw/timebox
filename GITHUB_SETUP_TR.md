# GitHub'a yükleme

## 1. Boş repo aç

GitHub'da sağ üstteki + menüsünden New repository seç. Adını `timebox` yap. Dersin raporunu ücretsiz GitHub Pages ile yayınlamak için Public seç. Bu paket README içeriyor; oluşturma ekranında ayrıca README ekleme. Create repository düğmesine bas.

## 2. Dosyaları yükle

Bu paketi ZIP'ten çıkar. Yeni reponun sayfasında “uploading an existing file” bağlantısına tıkla. ZIP dosyasını yükleme: içindeki README.md, firmware, docs, project ve GITHUB_SETUP_TR.md öğelerini birlikte sürükle. Üstteki `timebox` klasörünü tek bir alt klasör olarak yükleme; README.md doğrudan repo ana sayfasında olmalı. “Commit changes” ile kaydet.

## 3. Raporu aç

Repo içinden Settings → Pages aç. Source: Deploy from a branch. Branch: main. Folder: /docs. Save seç. Yayın tamamlandığında aynı sayfada rapor linki görünür. GitHub'ın gösterdiği linki kullan.

## 4. Teslim

Repo linki kodu ve belgeleri açar. Pages linki proje raporunu açar. Ders için bu iki linki kullan. Buzzer henüz çalışmadığı için raporda açık iş olarak kayıtlı.

GitHub ayarları için kaynak: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
